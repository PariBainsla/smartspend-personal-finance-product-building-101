# SmartSpend — Personal Finance Companion 💰

SmartSpend is a beginner-friendly, mobile-responsive personal finance website project designed to help students and young working professionals manage their finances.

## Problem Statement

Many young individuals struggle to track daily expenses, control monthly spending, and build consistent savings habits.

SmartSpend aims to simplify personal finance management through an intuitive and privacy-focused website.

## MVP Features

- Daily expense tracking
- Monthly budget management
- Savings goal tracking
- Financial overview dashboard
- Responsive UI/UX design

## AI Tools Used

| Tool       | Purpose                                   |
| ---------- | ----------------------------------------- |
| Perplexity | Market research and competitor analysis   |
| ChatGPT    | Customer discovery and Mom Test framework |
| ChatPRD    | Product Requirements Document             |
| Figma Make | UI/UX design and interactive prototyping  |

## Product Development Workflow

Market Research → Customer Discovery → PRD → UI/UX Design → Website Development

## Project Status

UI/UX prototyping and website development.

## Future Scope

- User authentication
- Secure data storage
- Improved expense categorization
- User testing and feedback

## Project Objective

Build a simple, accessible, and privacy-conscious personal finance website while applying AI-assisted product development techniques.
